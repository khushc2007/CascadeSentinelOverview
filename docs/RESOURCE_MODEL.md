# Phase 6 — resource and crossover model (V2 §16–17)

**Status of everything below: [ESTIMATED] analytical model with [DESIGN-STAGE] parameters unless a parameter's provenance says otherwise.**
The model is **not calibrated** (κ_cal needs the A2 micro-oracle, which does not exist), **not validated** against any synthesized circuit, and it makes **no quantum advantage claim**.
Code: `doomsday/resource/` (depends on nothing but its own modules; enforced by `tests/unit/test_dependency_rules.py`). Outputs: `results/phase6/`.

## What is modelled
G = 2·E_f + 2·C_D + C_refl Toffolis per Grover iteration; Q = c_q·√(N/M) quantum oracle calls; T_q = Q·G·t_T/√P_q; T_c = κ·N^α·t_c/P;
N* = (c_q·G·t_T·P / (κ·t_c·√P_q·√M))^{1/(α−½)} (no crossover for α ≤ ½). Oracle components, scenario membership (optimistic / realistic / pessimistic) and
formulas are V2 §16.2–16.3; `c_lab` (island detection) is **back-solved** from V2's printed ≈7×10⁴ (c_lab = 19), the once-only cost is k·L·⌈log₂L⌉+b (V2: "≈5×10³").
**Reproduction check** (V2 placeholders, IEEE-118, k=3): every printed V2 number is reproduced within 5% (G, T_q, N* for all three scenarios; logical qubits ≈4×10⁴). The residual differences
come from V2 printing two significant figures (e.g. pessimistic T_q 15.2 yr from the unrounded G vs. V2's 16 yr from the rounded 1.2×10⁹).

## Two Dicke-preparation scenarios (always reported separately; NOT equivalent)
| | what it is | status |
|---|---|---|
| `v2_assumed` | V2 §11.3: C_D = k·L·c_rot Toffoli-equivalents (Bärtschi–Eidenbenz O(kL)) | **ASSUMPTION** — the BE construction has **not been reproduced** here |
| `tree_counted` | exact operation counts of the **implemented** explicit-amplitude multiplexed-RY tree (analytic count verified against the real circuit for all 0≤k≤n≤10); each c-controlled RY is converted at 2(c−1)+c_rot Toffoli-equivalents | the count is exact; the **conversion factor is my estimate**, not from V2 |

At IEEE-118, k=3: C_D = 1.1×10⁴ (assumed) vs 3.2×10⁸ (tree, c_rot = 20): ×28,000, and the tree needs ≈1.0·N rotations (1.07×10⁶ for N = 1.06×10⁶; 4.9×10⁷ for N = 4.8×10⁷ at k=4).
Explicit amplitude loading therefore costs about as much as enumerating Ω_k; it is usable for toy circuits but **cannot** be a route to a crossover at IEEE scale, and no self-consistent k* exists
for it up to k=30. V2's O(kL) construction (if it can be realised) or the ranked-index encoding (V2's Tier C default; **not implemented**) would be needed. Nothing here supports treating the two costs as interchangeable.

## Cost classes kept distinct (every result)
* **quantum oracle calls** Q (Σ(j+1)-style, ideal), and optionally the certified-stop tail `c_tail·√N` (measured ≈9–10 on IEEE-14 emulation; V2 has no such term, default 0);
* **classical verifications** V = verif_per_qcall·Q at t_c each (≈0.3–0.55 per quantum call measured in emulation) — reported separately, <1% of quantum time;
* **preprocessing**: the N classical evaluations that Tier B *emulation* needs to build its predicate table — shown for information, **never** part of a coherent run's cost.

## Parameter provenance
Each parameter carries a source string: V2 placeholder, back-solved from V2, assumption, measured on the IEEE-14 Tier B emulation (unverified grid data), or informal diagnostic (not E1).
`results/phase6/measured_inputs_ieee14.json` holds the IEEE-14 inputs (R p50/p95/max = 1–3/5/6–7, keff p50/p95/max = 2–8/10–13/17–18, c_q discovery ≈2.5–2.7 per √(N/M), c_tail ≈9–10, informal t_c ≈1.1–1.6 ms DC in unoptimised Python).

## Findings (IEEE-118, k=3, V2 placeholders; see `results/phase6/resource_model.json`)
Classical exhaustive search is ahead in every scenario (T_q/T_c ≈ 36 optimistic, 3.9×10³ realistic, 9×10⁵ pessimistic, with the V2-assumed preparation). Self-consistent k* (using G(k)): 6 / 8 / 12 (P=1) and 11 / 14 / 18 (P=1000) for the V2-assumed preparation; none for the tree.
These are properties of the *model with its placeholders*, not measurements, and say nothing about real hardware. The tornado shows α (the classical scaling exponent) and the core count P dominate N*.
Physical qubits: ~6×10⁷ (V2 convention, d=23) to ~1×10⁸ (conservative, d=31) for the realistic scenario — bound quality; V2 quotes d≈25–31, and the lower end differs because the two use different simple error models.

## Caveats
* At IEEE-14 scale keff (up to 12) approaches L=20, outside the regime where the rank-|K| formulas are meaningful; the IEEE-14-scale rows are bound-quality illustrations only.
* The JavaScript port of the crossover explorer (V2 R1/§21) is Phase 9.
* Figure provenance: figures are generated by `scripts/phase6_resource_model.py` from the same in-memory data as the JSON. A first version of the tornado figure mislabelled its left panel (a shared y-axis let the right panel's labels overwrite it; `c_rot` appeared influential when it moves N* by <0.001 decades). It was caught by inspection, fixed, and is now guarded by an assertion in the script and a regression test.
* Reproduce: `PYTHONPATH=. python scripts/phase6_measured_inputs.py && PYTHONPATH=. python scripts/phase6_resource_model.py`.
